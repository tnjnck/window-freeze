Timing

What gets unloaded

Playing audio and already-unloaded tabs are always left alone.

Never freeze

One pattern per line, matched against the page URL. * matches anything; a line without * matches as a substring. Lines starting with # are ignored. The page context menu has "Never freeze this site"; freeze = never in a rule below does the same.

Per-site rules

A rule is one or more pattern lines (syntax as above) followed by key = value lines; a blank line ends it. Every rule whose pattern matches the page URL applies, least specific first (specificity = characters other than * in the pattern; ties in text order), each overriding the last. Lines starting with # are ignored.
Keys: style, blur, dim, color, showFavicon, showLabel, titleTemplate, labelTemplate, minutes, dwell, idleMinutes, protectForms, skipPinned, wholeWindow, preload, readerMaxChars, unloadedPrefix, freeze (never | normal).
Defaults, as a rule. A * block in your rules overrides these; more specific patterns override *.
